A comprehensive Python-based web scraper for extracting product information from Flipkart, Myntra, and Amazon e-commerce platforms.

Overview:

This project contains three separate web scrapers designed to extract product data from major Indian e-commerce websites:

Flipkart Scraper - Extracts product details, prices, ratings, and reviews

Myntra Scraper - Focuses on fashion products with variant information

Amazon Scraper - Retrieves comprehensive product data from Amazon India
